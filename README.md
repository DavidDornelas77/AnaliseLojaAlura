# AnaliseLojaAlura
# Análise de Dados de Vendas de Lojas

## Descrição

Este projeto tem como objetivo analisar os dados de vendas de quatro lojas, a fim de identificar padrões, tendências e insights que possam auxiliar na tomada de decisões estratégicas, como a venda de uma das lojas.

## Dados

Os dados utilizados neste projeto foram obtidos de arquivos CSV contendo informações sobre as vendas de cada loja, como:

* Data da venda
* ID do produto
* Categoria do produto
* Preço do produto
* Quantidade vendida
* Avaliação da compra
* Frete
* Latitude e longitude da loja

## Análises Realizadas

As seguintes análises foram realizadas neste projeto:

* **Análise do faturamento:** Cálculo do faturamento total de cada loja e comparação entre elas.
* **Vendas por categoria:** Identificação das categorias de produtos mais vendidas em cada loja.
* **Média de avaliação das lojas:** Avaliação da satisfação dos clientes de cada loja.
* **Produtos mais e menos vendidos:** Identificação dos produtos mais e menos vendidos em cada loja.
* **Frete médio por loja:** Cálculo do frete médio cobrado por cada loja e comparação entre elas.
* **Análise dos dados disponíveis:** Análise geral dos dados, considerando faturamento, despesas com frete, quantidade de produtos vendidos e avaliação da loja, para auxiliar na decisão de qual loja vender.

## Visualizações

Gráficos de barras, gráficos de linha e gráficos de dispersão foram utilizados para visualizar os resultados das análises e facilitar a compreensão dos dados.

## Conclusões

Com base nas análises realizadas, foi possível identificar insights importantes sobre as vendas de cada loja, como:

* A loja 4 apresentou o menor faturamento e o segundo pior desempenho em avaliação dos clientes, tornando-a uma candidata à venda.
* As demais lojas apresentaram diferentes pontos fortes e fracos, como maior faturamento, maior quantidade de produtos vendidos ou melhor avaliação dos clientes.
